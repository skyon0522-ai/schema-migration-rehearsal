Scope and limits

This screen checks saved, editable records for one synthetic PostgreSQL contract. It does not run a database, probe current processes or authenticate the records. Worker SIGKILL is not power-loss recovery. The fixed old-client gate is not a distributed deployment protocol or a production availability guarantee. Use stable owner-controlled files; concurrent hostile filesystem changes are outside this check.

Focus wide tables to scroll with a keyboard. There are no external fonts, scripts or network resources.
