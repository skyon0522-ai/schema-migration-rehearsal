## Public evidence treatment

Original receipts remain private and unchanged. Staged evidence replaces personal/local absolute path prefixes with placeholders, or replaces independent-review file links with equivalent relative links. Timestamps, identifiers, numeric results, conclusions, source hashes, rows and SQLSTATE values are preserved. [verification/redactions.json](verification/redactions.json) lists original and staged hashes and redaction counts; the private curation report retains every exact original/new value and JSON pointer or text line. The sanitized receipt's SHA-256 necessarily differs from the original hash quoted by the independent review.

The repository contains no cluster files, virtual environment, native executable, wheel, source archive, cache or personal workspace path. Upstream/dependency licenses are retained byte-for-byte rather than edited.
